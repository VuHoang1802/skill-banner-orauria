# Prompt template

Lưu prompt nguồn dùng lại được tại đây dưới dạng `.txt`. Một bộ có thể chứa nhiều prompt, ngăn cách bằng dòng chính xác `**----**`. Template chỉ cung cấp cảm hứng về bối cảnh, bố cục, ánh sáng, đạo cụ, hiệu ứng và layout; không tin cậy mô tả sản phẩm, logo, claim, giá, khuyến mãi hoặc nội dung thương hiệu trong template.

Dùng tên file ổn định. Sau khi template đã được dùng trong batch, không sửa file đó; hãy tạo phiên bản mới như `social-ads-v2.txt` để có thể tái hiện các lần chạy cũ.
